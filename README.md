# Sarvesh Gowda P H — Product Management Portfolio

A clean, modern grey and black themed portfolio website showcasing product case studies, UX flows, leadership initiatives, and analytical frameworks.

## 🚀 Free Deployment on GitHub Pages

This portfolio is built with zero-build pure semantic HTML5, CSS3, and JavaScript — designed to deploy instantly for free on GitHub Pages.

### Deployment Steps:
1. Create a new GitHub repository named `portfolio` on your GitHub account (`phsarvesh765-max`).
2. Push this directory to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit: Sarvesh Gowda P H portfolio"
   git branch -M main
   git remote add origin https://github.com/phsarvesh765-max/Product_Portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**
   - Select branch **main** and folder **/(root)**, then click **Save**.
4. Your site will be live at `https://phsarvesh765-max.github.io/Product_Portfolio/` within minutes!
